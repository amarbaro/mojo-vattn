# mojo-vattn v0.1.0

**Released:** 2026-10-26 · **Commit:** the one tagged `v0.1.0` · **Previous:** first release

## What it does

A flash-attention forward kernel in Mojo for video DiT self-attention shapes on the AMD RX 7900 XTX (gfx1100): non-causal, no mask, f16, head dimension 128, layout `[L, H, D]`, with a parity harness against an fp64 reference.

## Highlights

- Any sequence length: tail rows and keys are masked.
- Matches the fp64 reference to a max abs error under 9.3e-4 on L = 129 (H 4) and L = 1000 (H 2), gate 2e-3.
- No speed claim: not faster than PyTorch SDPA, not wired into any framework.

## Changes

First public release, no earlier version.

## Known limits

- gfx1100 only, f16, head_dim 128, non-causal, no mask, batch 1.
- No timing receipt in the tree; the parity gate does not run on GitHub.
