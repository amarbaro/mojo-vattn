## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
A flash-attention forward kernel in Mojo for video DiT self-attention shapes on the AMD RX 7900 XTX (gfx1100): non-causal, no mask, f16, head dimension 128, layout `[L, H, D]`, with a parity harness against an fp64 reference.

## Highlights

- A tile configuration the K/V loaders cannot cover (for example `VATTN_BM=96`) fails at compile time instead of producing non-finite output.

## Changes

### Added
- Package layout `src/vattn/` and `recipe.yaml`, a conda package recipe that pins MAX 26.7.0.
- `docs/design.md`: what ships.
- CI, latest-release and license badges in the README.
### Changed
- README names the MAX 26.7.0 wheel pinned in `pyproject.toml`.
- `docs/api.md`: `scale_log2` is applied to the scores, not folded into Q.
### Fixed
- Tile configs the K/V loaders cannot cover are refused at compile time.
